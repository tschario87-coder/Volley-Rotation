# Volleyball-Rotation

Interaktives Volleyballfeld für den Sportunterricht: Positionen 1–6, Rotation im 5-1-System,
Wechsel auf die Spezial-Plätze nach dem Aufschlag und Ballwechsel-Animation (eigener Aufschlag / Gegner-Aufschlag).

- Reine HTML-Seite, kein Build nötig
- Läuft auf Handy, Tablet, Laptop und Beamer
- Installierbar („Zum Home-Bildschirm“) und offline nutzbar

## Lokal ansehen
`index.html` im Browser öffnen.

## Veröffentlichen
GitHub-Repository erstellen, Dateien hochladen, auf vercel.com „Add New → Project“ → Repository importieren → Deploy.
Framework Preset: **Other**, kein Build-Befehl.
